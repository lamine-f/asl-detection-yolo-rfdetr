--------------------------------------------------------------------------------
 FAITS SAILLANTS
--------------------------------------------------------------------------------

  PERFORMANCE NOMINALE (test set, 72 images)

      Métrique           YOLO11n      RF-DETR-S
      mAP@0.5            0.904        0.901
      mAP@0.5:0.95       0.875        0.881
      Latence (T4 GPU)   36.4 ms      132.8 ms
      FPS                27.5         7.5
      Taille modèle      5.21 MB      121.8 MB

  -> Précision quasi identique. YOLO est ~3.6x plus rapide et 23x plus léger.

  ROBUSTESSE (5 conditions dégradées : luminosité + bruit gaussien)

      Condition          YOLO Δ%      RF-DETR Δ%
      gamma = 1.5        +1.3         +0.8
      gamma = 0.75       -1.0         -0.8
      gamma = 0.5        -3.5         -0.8
      sigma = 15         -2.1         +0.1
      sigma = 35         -76.8        -1.1
      Chute moyenne      16.9%        0.7%

  -> RF-DETR-S est dramatiquement plus robuste. YOLO s'effondre à 0.21 mAP
     sous bruit fort tandis que RF-DETR reste à 0.89.

  -> Recommandation : YOLO pour edge / temps réel en environnement maîtrisé,
     RF-DETR pour environnement bruité ou non maîtrisé.

 RELANCER LA DÉMO LOCALEMENT (3 commandes)
--------------------------------------------------------------------------------

  git clone https://github.com/lamine-f/asl-detection-yolo-rfdetr
  cd asl-detection-yolo-rfdetr
  ./scripts/download_models.sh    # télécharge les modèles depuis Hugging Face
  python app/gradio_app.py        # ouvre http://127.0.0.1:7860

  Ou via Docker :
      docker compose up -d --build
